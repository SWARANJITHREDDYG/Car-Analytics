# Final Project Report — Automotive Market Analytics

## Project Overview
This project analyzes automotive market data to understand pricing trends,
performance factors, and customer preferences using data analytics techniques.

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Power BI
- Git & GitHub

## Task-wise Summary

### Task 1 — Data Wrangling
- Cleaned raw car sales data
- Handled missing values and duplicates
- Standardized numeric and categorical fields

### Task 2 — Exploratory Data Analysis
- Analyzed price distribution and trends
- Studied relationships between price, car age, mileage, engine capacity
- Identified key market patterns using visualizations

### Task 3 — Dashboard & Storytelling
- Built an interactive Power BI dashboard
- Added KPIs, charts, and slicers
- Converted EDA insights into business-friendly storytelling

### Task 4 — Insights & Recommendations
- Derived key business insights
- Provided actionable recommendations for stakeholders
- Focused on data-driven decision-making

## Key Outcomes
- Identified depreciation patterns in used cars
- Recognized performance-based pricing factors
- Highlighted regional and brand-based pricing differences

## Conclusion
This project demonstrates end-to-end data analytics skills,
from data preparation to visualization and business insight generation.
