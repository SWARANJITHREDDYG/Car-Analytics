# Task 4 — Business Recommendations

## 1. Inventory Strategy
Dealers should prioritize stocking newer vehicles with lower car age to maximize resale value.

## 2. Premium Segment Focus
Higher engine capacity and automatic transmission vehicles should be marketed as premium offerings.

## 3. Fuel-Based Targeting
Diesel vehicles can be positioned as value-for-money options for long-distance users.

## 4. Regional Pricing Strategy
Pricing strategies should be adjusted based on location to reflect regional demand patterns.

## 5. Brand Positioning
Premium brands should focus on quality and performance messaging, while mass brands should emphasize affordability.
